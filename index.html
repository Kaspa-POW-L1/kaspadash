What makes Kaspa unique?ⓘA quick introduction to Kaspa's core innovations for visitors who are new to the project.

GHOSTDAG / BlockDAG — Unlike Bitcoin where only one block per ~10 minutes is accepted, Kaspa accepts all blocks created simultaneously. This is possible through the GHOSTDAG protocol, which orders parallel blocks mathematically. Result: 10 blocks per second without sacrificing security or decentralisation.

Proof of Work — Kaspa uses the kHeavyHash algorithm, deliberately ASIC-friendly. This means professional miners provide long-term security, just like Bitcoin. No proof-of-stake shortcuts.

Chromatic halving — Instead of a sudden halving every 4 years (like Bitcoin), Kaspa reduces the block reward by ½^(1/12) every month — a smooth, predictable emission curve toward a hard cap of ~28.7B KAS.

Fair launch — No premine, no ICO, no investor allocation. All KAS was and is earned through mining.

Rust implementation — The node software (rusty-kaspa) is written in Rust, known for memory safety and performance. The codebase is open source.
